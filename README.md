# Helicopter Game

A first-person helicopter tunnel flying game built with pure HTML5 Canvas.

**No dependencies. Single file. Works offline.**

## How to Play

1. Download `index.html`
2. Open it in any modern browser (Chrome / Safari / Edge recommended)
3. On mobile: open the file directly or host it

### Controls
- **Touch & drag** anywhere on screen = virtual joystick
- **Up / Down** = climb / descend
- **Left / Right** = bank / turn
- **Hold still in center** = boost forward

## Features

- Procedural endless tunnel
- Coins & gems scoring system
- Cinematic takeoff sequence
- Cockpit flight view
- Particle effects & screen shake
- Best score saved in `localStorage`

## Files

| File | Description |
|------|-------------|
| `index.html` | Complete game (HTML + CSS + JS + all images embedded as base64) |

> **Note:** The game file is ~8.2 MB because all visual assets (splash, helicopter, cockpit, scenes) are embedded for a fully offline experience.
